# ANOARTIFACT — 異常管理社

PC / iPad対応、見下ろし型の2Dアクションローグライクの初期Web版です。1〜4人のルームコード式協力プレイに対応します。

## ルール

- **NORMAL**: 15ステージ。ステージ5 / 10 / 15でボス。
- **HARD**: 20ステージ。ステージ5 / 10 / 15 / 20でボス。全ての敵とボスのHPと攻撃力はNORMAL基準の**2倍**。
- ボスの攻撃パターンは複数候補から探索ごとに選ばれ、戦闘中も切り替わります。
- **裏ステージ**: 「ハード20ステージを**ソロで**クリア」かつ「ANOMALY ARTIFACT図鑑の12種類すべてを発見」で開放。通常・ハードのクリア条件とは別です。
- 裏ステージは冒頭に偽の「STAGE CLEAR」が表示されます。その直後、**the anomaly**（異常管理社の元代表）が上空から落下して出現します。独自の異常遺物モチーフ攻撃を行います。
- 毎ステージクリア後、3つの報酬候補から遺物を1つ選べます（最大装備6つ）。発見した遺物は図鑑に登録されます。
- 記録（図鑑・ソロハードクリア・裏ステージ突破）はブラウザのlocalStorageに保存されます。

## 操作

PC:
- WASD / 矢印キー: 移動
- マウス: 照準 / 左クリック長押し: 攻撃
- Space: 回避ダッシュ
- Q: 「重力の釘」（装備時）
- E: 「逆行する砂時計」（装備時）

iPad:
- 左スティック: 移動
- 右側の攻撃ボタン、またはゲーム画面の右側のドラッグ: 照準・攻撃
- Q / E / 回避: 画面上のボタン
- 攻撃ボタン使用時は近くの敵への簡易照準補助が働きます

## ローカル実行

Node.js 20以上を推奨します。

```bash
npm install
npm start
```

http://localhost:3000 を開きます。ヘルスチェックは `GET /healthz` です。

## Render

- Node.js Web Service
- Build command: `npm install --omit=dev`
- Start command: `npm start`
- Region: Singapore
- `PORT` 環境変数はRenderが渡す値を使います
- WebSocketはWeb Service内の `/ws` を使用します

## 実装済みと今後の課題

このリポジトリは空の状態から作成した**プレイ可能な初期プロトタイプ**です。基本移動、射撃、回避、敵AI、ボス弾幕、ステージ進行、報酬選択、12種類の遺物、図鑑、裏ステージ解放、1〜4人の同室協力戦闘を含みます。

**正式版向けの未実装要素**:
- 認証・サーバー側データベースへの永続記録。現在の解放記録は端末単位であり、開発者ツールで書き換え可能です（競争用途の認証としては使用しないでください）。
- ステージ中の再接続 / 途中参加、ダウン状態からの蘇生、アイテムトレード。
- 複数部屋をつなぐ探索マップ、恒久マスタリー、複雑なパズル、進化する敵AI。
- サーバー再起動時の進行保存。現状、再起動によって進行中のオンラインルームは消えます。

マルチプレイの戦闘判定はサーバーが担当します。ブラウザから任意のダメージや撃破数を送り込むことはできませんが、未認証のローカル解放記録は正式な権限管理ではありません。
